✨ Key Features

🎯

Lipschitz-Adaptive LR

Automatically adjusts learning rates based on local loss curvature. Larger steps in smooth regions, smaller in steep areas.

📊

Information-Weighted Sampling

Prioritizes high-loss (high-information) samples. Three-phase training: warmup → thermodynamic → consolidation.

⚡

Real Energy Tracking

Multi-backend support: NVML (NVIDIA), PowerMetrics (Apple), TDP fallback. Measures η = ΔI/E (bits/joule).

🔬

Thermodynamic Theory

Based on information thermodynamics. Treats learning as energy-to-information conversion process.

🐍

PyTorch Compatible

Drop-in replacement for Adam. Works with existing training code. Full type hints and documentation.

✅

Production Ready

Validated on real hardware. Available on PyPI. Comprehensive tests and examples included.

🧠 How It Works

1️⃣ Warmup Phase

Uniform sampling for stable initialization. Learn the general structure of the problem.

2️⃣ Thermodynamic Phase

Focus on high-information samples (top 65%). Maximize efficiency with Lipschitz-adaptive learning rates.

3️⃣ Consolidation Phase

Return to uniform sampling. Ensure all examples are well-represented in final model.
